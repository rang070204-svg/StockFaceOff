# 종목 비교 인터랙티브 대시보드

**"A와 B 중 뭐가 나았을까?"** — 종목 2~3개를 골라 같은 화면에서 직관적으로 비교하는 웹앱입니다.

투자 초보도 표가 아닌 그래픽으로 종목의 흐름을 한눈에 이해할 수 있도록 만들었으며, [hyorang.com](https://hyorang.com) 블로그에서 직접 체험할 수 있습니다. 오픈소스 도구를 활용해 직접 만들어가는 과정 역시 블로그에 기록하고 있습니다.

## 무엇을 할 수 있나요

- **라이벌 비교 프리셋** — 삼성전자 vs SK하이닉스, 애플 vs 마이크로소프트 등 한 번의 클릭으로 비교 시작
- **수익률 라인차트** — 시작점을 0%로 맞춰 "같은 돈을 넣었다면" 관점에서 비교
- **핵심 지표 카드** — 현재가, 기간 수익률, 최대 낙폭을 큼직한 숫자로 나란히
- **레이더 강점 비교** — 수익률·변동성·모멘텀 등을 겹쳐 강약을 시각화
- **승부 요약** — "수익률은 A 승, 안정성은 B 승" 한 줄 정리

한국 주식은 6자리 코드만 입력하면 자동 인식하며, 기간은 1개월부터 3년까지 선택할 수 있습니다.

## 기술 구성

Python · Streamlit · yfinance · Plotly로 만들어졌고, Docker로 패키징되어 Render에서 서비스됩니다. 디자인은 Pretendard 폰트 기반의 핀테크 미니멀 스타일입니다.

로컬에서 실행해보려면:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 면책

본 앱은 과거 시세 데이터(Yahoo Finance) 기반의 단순 비교 자료이며, 특정 종목에 대한 매수·매도 추천이나 투자 자문이 아닙니다.
